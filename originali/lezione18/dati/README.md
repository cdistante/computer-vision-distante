# Dati di Foundation Vision Studio

Il notebook usa sei immagini fissate di PennFudan: PennPed00014, PennPed00022, PennPed00035, FudanPed00042, FudanPed00058 e FudanPed00063. Il dataset non è redistribuito. C05 lo acquisisce dalla [fonte originale](https://www.cis.upenn.edu/~jshi/ped_html/PennFudanPed.zip); conservarne crediti e condizioni.

Le maschere e le metriche in recupero/ sono risultati dell’esecuzione CPU originale, non un nuovo addestramento o una nuova inferenza. Il protocollo usa coordinate assistite dalla GT e distingue la segmentazione di istanza SAM dalla previsione semantica LRASPP.
