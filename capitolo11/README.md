# Capitolo 11 — Rilevamento: geometria, selezione e AP

Aprire `capitolo11.ipynb` in Google Colab oppure in Jupyter e procedere dall’inizio. CPU, NumPy e Matplotlib; dati sintetici autocontenuti.
